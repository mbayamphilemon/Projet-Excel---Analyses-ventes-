# Projet-Excel---Analyses-ventes-
Projet professionnel réalisé avec Excel pour transformer des données commerciales brutes en informations décisionnelles à travers le nettoyage, l’analyse, les KPI et un dashboard interactif.
# 📊 Analyse Commerciale avec Excel

## 🎯 Objectif
Analyser les performances commerciales afin d'identifier
les produits, commerciaux, régions et segments clients
les plus performants.

## 🛠️ Technologies
- Microsoft Excel
- Power Query
- Tableaux croisés dynamiques
- Formules Excel
- KPI
- Data Visualization

## 📌 Analyses réalisées

- Chiffre d'affaires
- Bénéfice
- Marge
- Taux de marge
- Performance des commerciaux
- Performance des produits
- Analyse des régions
- Analyse des clients
- Modes de paiement
